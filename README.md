# Count Island

> **Connected-component labeling algorithm on 2D grids in C.**

## Overview
Recursively identifies, labels, and counts connected components ("islands") represented on a 2D text map. Discovers adjacent matching cells and assigns an incremental numeric label to each contiguous landmass.

## Build & Usage
```bash
make
./count_island map.txt
```
